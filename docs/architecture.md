# 아키텍처

2026-10-29 기준 구현을 설명한다. macOS UI 실행 결과는 [배포 상태](release.md), 제공자별 실계정 결과는 [제공자 참조](providers.md)에 있다.

## 프로세스와 데이터 소유권

AppKit 호스트 `light-usage-bar`는 메뉴 막대, 갱신 서비스, 인증 정보 읽기와 메모리 캐시를 소유한다. GPUI 실행 파일 `light-usage-panel`은 표시 전용 스냅샷을 받아 상세 패널을 그린다. 배포 단위는 실행 파일 두 개를 포함한 앱 번들 하나다.

| Crate | 역할 |
| --- | --- |
| `usage-core` | 사용량 단위, 사용과 잔여 방향, 기간, 출처, 성공 값과 조회 상태 |
| `usage-providers` | 인증 정보 선택, 읽기 전용 요청, 응답 파서, 서버와 로컬 계정 검증 |
| `usage-service` | 갱신 일정, 동시 실행 제한, 취소와 종료, 제공자 설정 저장 |
| `usage-display` | 계정 식별자와 인증 정보를 제외한 표시 모델, IPC 검증 |
| `usage-app` | AppKit 메뉴와 호스트, 패널 프로세스 수명 |
| `usage-panel` | GPUI 상세 화면과 사용자 명령 전달 |

호스트는 패널을 열 때 보조 프로세스를 실행한다. 닫기 요청 후 2초 내 종료하지 않으면 종료시키고 회수하는 경로가 있다. 시작 응답과 IPC 프레임에도 제한 시간을 둔다. 이 구조가 단일 프로세스보다 적은 메모리를 쓴다는 실측 결과는 없다. 구조 선택의 근거와 남은 비교는 [ADR 0001](decisions/0001-ui-process-lifecycle.md)을 따른다.

## 스냅샷과 조회 상태

성공 스냅샷은 한도 구간, 사용량 또는 잔여량의 단위, 초기화 시점, 출처와 조회 시각을 보존한다. 모르는 값은 `Unknown`이다. 체험 만료와 구독 초기화는 다른 필드다. 100%를 초과한 값도 보존한다.

조회 중 상태와 오류는 마지막 성공 값과 분리한다. 일반적인 통신 오류가 발생해도 마지막 값을 지우거나 0으로 바꾸지 않는다. 로컬 인증 정보의 변경이나 선택한 계정과 다른 서버 응답은 기존 값을 무효화한다. 로컬 인증 정보를 읽지 못할 때도 이전 선택과 값을 제거한다.

성공 값의 신선도는 120초 기준이다. 기본 갱신은 600초이므로 다음 정기 조회 전에도 `Stale`이 될 수 있다. `Stale`은 새로운 조회 실패와 같은 뜻이 아니다. 성공 값은 메모리에만 저장하며 앱 재시작 후 재사용할 디스크 사용량 캐시는 없다.

## 갱신 일정과 취소

서비스는 제공자별 한 요청, 전체 두 요청까지 실행한다. 성공 후 600초 뒤 다음 조회를 예약한다. 수동 갱신도 요청 시작 간 최소 30초 제한을 따른다. 진행 중 요청은 중복 실행하지 않는다.

일시적인 실패는 지수 지연과 jitter를 적용한다. 기본 지연은 30초부터 1800초까지 증가한다. 서버의 `Retry-After`가 더 길면 그 시각을 따른다. 제공자를 껐다 켜거나 패널을 다시 열어도 제한을 해제하지 않는다.

인증 필요, 권한 거부, 미지원과 검증 필요 상태는 자동 재시도를 멈춘다. 사용자는 원인을 해결한 후 수동 갱신할 수 있다. 절전 복귀 시 밀린 간격마다 요청하는 대신 필요한 조회를 합친다.

비활성화와 종료는 진행 중 작업에 취소를 전달한다. Keychain 보조 프로세스는 취소나 제한 시간 초과 시 종료와 회수를 마친 후 작업을 끝낸다. 네트워크와 자격 증명 읽기는 AppKit 주 스레드 밖에서 실행한다.

## IPC와 인증 경계

호스트와 패널은 전용 stdin과 stdout pipe로 통신한다. 메시지에는 버전, 세션, 표시용 값과 제한된 사용자 명령을 넣는다. 프레임 크기와 텍스트 길이, 수치, 제공자 중복을 검증한다. 인증 토큰, 계정 ID, workspace ID와 응답 원문은 표시 모델에 넣지 않는다.

패널은 제공자에 직접 접속하지 않는다. 호스트는 패널 실행 환경을 제한한다. macOS Keychain 조회에는 같은 호스트 실행 파일의 별도 내부 실행 모드를 사용한다. 이 모드는 일반 진단 명령이 아니며 직접 실행하면 안 된다. 인증 데이터는 전용 pipe로만 수집한다.

영구 저장하는 앱 설정은 제공자 네 개의 활성화 여부다. 경로와 네트워크 목적지는 [개인정보 설명](privacy.md)에 정리한다.
