# 벤치마크 기록

갱신일은 2026-10-30이다. 패널을 열지 않은 4시간 대기 관찰 1건을 완료했다. 비교 성능은 미측정이다.

아래의 빈칸과 `미측정`은 실제 수치를 대체하는 표시이며, 0 MB 또는 성능 우위를 뜻하지 않는다.

측정 절차와 지표 정의는 [성능 계획](performance.md)을 따른다. 이 문서에는 실제 실행 조건, 결과, 재현 자료만 추가한다.

## MacBook Pro의 4시간 초기 대기 관찰

2026-10-30 07:04:04부터 11:04:04 KST까지 M3 Pro MacBook Pro, RAM 18 GiB, macOS 26.6.2에서 1회 관찰했다. AC 전원을 사용했다. 대상은 소스 `a8eb02e58ee9d11744a12eaeb51ac3cac0d17dae`의 release 앱이며, LaunchServices로 일반 실행했다. 이 실행은 `font-kit` 수정 전이며 Mac mini의 화면 검증과 별개다. 실행 기록상 패널은 열지 않았다. 수집기 자체는 패널 상태를 독립적으로 확인하지 않는다.

| 항목 | 관찰 결과 |
| --- | --- |
| 지표 | `footprint` JSON의 host process footprint. 원래 단위는 byte |
| 유효 표본 | 241개. 수집 기간 14,400초, 목표 간격 60초 |
| 중앙값 | 11,567,872 B, 11.032 MiB |
| 최솟값과 최댓값 | 11,387,648 B부터 11,715,328 B. 10.860 MiB부터 11.173 MiB |
| 수집과 검증 오류 | 0개. 원본 footprint의 오류와 경고도 0개 |
| 관찰 프로세스 | 동일 host process. 탐색 시점에 자식 프로세스는 관찰되지 않음 |
| 제공자 요청과 실패 횟수 | 수집하지 않아 알 수 없음 |

네 번의 wall-clock 표본 간격은 62초였다. 같은 지점에서 기록된 boot-time 값이 2초씩 변했고 원본 Mach time도 약 4시간을 나타냈다. 따라서 정확히 60초마다 수집했다고 하거나 이 간격을 앱 정지로 해석하지 않는다. 시계 조정의 구체적 원인은 확인하지 않았다.

저장된 분석은 원본 자료로 다시 실행한 결과와 일치했다. MiB는 1,048,576바이트다. 위 값은 표본에서 관찰한 host footprint이며 전체 앱의 고유 물리 메모리 총량이 아니다. 순간적으로 실행된 자식 프로세스는 탐색 사이에 누락될 수 있다. 실제 활성 제공자 구성과 조회 성공 횟수도 확정하지 않았다.

이 1회 결과는 다른 앱과의 비교, 반복 재현성, 누수 없음, 패널 사용 후 상주 비용이나 MVP 성능 통과를 입증하지 않는다. 50회 패널 반복, 패널 사용 후 4시간 상주, sleep 및 wake와 에너지 측정은 남아 있다.

## 비교 묶음

| 묶음 | 후보 | 제공자 조건 | 비교 목적 |
| --- | --- | --- | --- |
| A | Light Usage Bar, CodexBar | 두 앱에서 실제 검증된 동일 제공자 집합. 우선 Claude + Codex를 검토 | 주 비교: 복수 구독을 보는 일상 상주 비용 |
| B | Light Usage Bar, claudebar | Claude만 활성화 | Claude 전용 조건의 상주 비용 |
| C | Light Usage Bar, Aura, ai-usagebar | 해당 빌드가 지원하는 공통 제공자만 활성화 | 다른 구현과 같은 기능 범위에서 비교 |
| D | Light Usage Bar | Grok Bot 및 Antigravity를 각각 추가한 조건 | 제공자 한 개를 추가할 때 생기는 수집 비용 |

비교 앱을 한꺼번에 실행하지 않는다. 원격 상태와 인증 조건을 가능한 한 맞추어 순차적으로 실행하고, 실행 순서에 따른 영향을 줄이기 위해 반복 순서를 바꾼다. Grok Bot 구독 사용량과 xAI API 잔액처럼 의미가 다른 기능은 동일한 제공자로 취급하지 않는다.

같은 갱신 주기를 설정할 수 없다면 변경 가능한 공통 조건의 실험과 앱 기본값 실험을 구분한다. 기본값이 다른 결과를 같은 조건의 성능 순위로 제시하지 않는다.

## 공개할 자료

버전, 설정, 측정 절차, 비밀을 제거한 수치와 집계 방법을 공개한다. 필요하면 작은 CSV나 JSON 자료를 함께 커밋한다. 원본 인증 응답, 토큰, 쿠키, 계정 식별자, 개인 파일 경로가 포함된 로그·스크린샷은 공개하지 않는다.

하나의 Mac에서 얻은 값은 그 환경의 결과다. Apple Silicon과 Intel, macOS 버전, 제공자 구성 또는 측정 도구가 다르면 결과를 분리한다. 앱을 사용하기 전 대기 상태만으로 실제 사용 이후의 메모리 절감률을 주장하지 않는다.
